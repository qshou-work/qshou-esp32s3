# Y71t 被控端准备清单（android_prep 可执行版）

> 来源：规格 `android_prep` 章节（mandatory: true）。
> 以下设置在**首次部署前一次性完成**，逐项勾选；完成后截图/记录留存，避免重复踩坑。
> 本清单只描述「在 Y71t（vivo Y71t / OriginOS）上怎么操作」，不解释原理——原理见规格对应章节。

## 1. 显示（display）

- [ ] **开启「指针位置」**：设置 → 系统管理/关于手机 → 开发者选项 → 打开「指针位置 (Pointer location)」
      - 这是坐标链路的**唯一地面真值来源**，后续所有 tap/swipe 落点都以它为准
- [ ] **自动息屏改为「永不」或最长档**：设置 → 显示 → 自动熄屏 → 永不
- [ ] **亮度手动拉满 + 关闭自动亮度 + 关闭护眼模式（滤蓝光）**
      - 护眼会改变画面色调，破坏图像比对基线
- [ ] **关闭深色主题 / 改为浅色主题**
      - AMOLED 深色界面在摄像头下难以辨识边界

## 2. 蓝牙（bluetooth）

- [ ] 蓝牙保持常开，完成与 ESP32 的**一次配对**
- [ ] **OriginOS 电池优化**：将蓝牙及相关系统服务加入白名单（激进省电策略的保险）
- [ ] 配对完成后，在「已配对设备」里确认该设备归类为**输入设备**
      - 否则后续 tap 可能无效（这是选型结案后仍需现场确认的一点）

## 3. 锁屏（lockdown）

- [ ] 关闭锁屏密码 / 指纹，或设为**滑动解锁**
      - 否则黑屏下摄像头看不到内容且无法操作
- [ ] 关闭「抬起亮屏 / 双击亮屏」等手势，减少误触发导致画面抖动

## 4. 长期供电（long_term_power，HIGH 风险）

> 7×24 插电 + 屏幕常亮会同时命中锂电池鼓包与 AMOLED 烧屏两个陷阱。
> 采用 Tier-A：保留原电池 + 智能插座窄窗口循环，目标 SOC 区间 **45–65%**。

- [ ] 使用 **5V/1A（5W）普通充电器**，**明确禁用 44W 闪充头**
      - 闪充补 20% 只需几分钟，插座开关窗口窄到不可控；慢充让「开多久=补多少」由物理速率保证
- [ ] 实机标定一次放电速率（见 B4 任务）：屏幕常亮+满载时，60%→40% 需多少小时
- [ ] 据放电速率设智能插座补电窗口，维持 SOC 在 45–65%（宁可偏低不要偏高）
- [ ] 选**本地执行定时**的智能插座（断外网时云调度会失效，本地 schedule 仍在跑）
- [ ] 每周复核一次 SOC 区间实际漂移（相机看状态栏电量即可）

## 5. 息屏行为验证（verification_required，上线前必做）

- [ ] 熄屏 30 分钟后发送一次 HID tap，记录：连接是否还在 / 屏幕是否被唤醒 / tap 是否生效
- [ ] 若 (a) 连接断：补串口日志看是 ESP32 侧还是 Y71t 侧发起断连
- [ ] 若 (b) 未唤醒但连接还在：说明触控不触发唤醒，必须回退到常亮策略

## B3 标定图验证步骤（配合 `fixtures/calib_grid.png`）

1. 把 `calib_grid.png` 推到 Y71t 或放到本地 Web 服务器，用**系统浏览器**全屏打开
2. 确认：全屏后**无浏览器地址栏/导航栏残留**、AMOLED 黑底不发光处能取到特征
3. 若深色背景下特征点取不到，改生成浅色底版本（改 `tools/gen_calib_grid.py` 的 bg 参数）
